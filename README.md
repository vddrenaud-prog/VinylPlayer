# VinylPlayer
VinylPlayer est un lecteur musical Android open source et 100 % hors-ligne. Basé sur Capacitor.js, il intègre un plugin natif Java sur mesure (MediaLibraryPlugin) pour contourner les limites des WebViews : il gère les permissions système, scanne les fichiers .mp3 locaux et interprète nativement les playlists .m3u.
